# Malchain
MalChain is an Open-source malware kill chain framework with 42 techniques, CVE mappings, and detection methods

## Overview

MalChain is a comprehensive framework for understanding malware behavior, organized across 6 attack phases from initial access to data exfiltration. It includes CVE mappings, detection methods, and real-world malware analysis.

## Framework Structure

| Phase | Techniques | Focus |
|-------|-----------|-------|
| Initial Access | 7 | How malware enters systems |
| Execution | 7 | Running malicious code |
| Persistence | 7 | Maintaining presence |
| Defense Evasion | 7 | Avoiding detection |
| Lateral Movement | 7 | Spreading within networks |
| Exfiltration | 7 | Stealing data |
